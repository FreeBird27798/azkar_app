# Hisn al-Muslim (Azkar & Subhah) 📿

A professional and comprehensive Islamic application built with **Flutter**. This app brings the complete collection of the **"Hisn al-Muslim"** (Fortress of the Muslim) book to your fingertips, featuring a modern UI and 100% offline functionality.

## ✨ Key Features
- **Complete Hisn al-Muslim:** Includes all authentic Adhkar and supplications from the famous book.
- **Offline Access:** No internet connection needed; all data is stored locally for instant access.
- **Digital Subhah:** An interactive and simple counter for Tasbih.
- **Search & Categorization:** Easy navigation through different types of remembrances.
- **Multilingual Support:** Fully localized using Flutter's Internationalization (i18n).
- **Reactive UI:** Smooth state management and navigation powered by **Provider**.

## 🛠️ Tech Stack
- **Framework:** Flutter (Dart)
- **State Management:** Provider
- **Data Management:** Local Database / Asset-based JSON.
- **Localization:** Flutter Internationalization

## 🛠️ Installation
1. Clone the repository.
2. Run `flutter pub get`.
3. Build and run on your Android or iOS device.
